# 🚀 WP Admin Manager

A secure and elegant WordPress user management tool with a modern glass-morphism UI. This script allows you to quickly create or delete administrator accounts directly from a custom interface.

![WordPress](https://img.shields.io/badge/WordPress-5.0%2B-blue?style=flat-square&logo=wordpress)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

---

## ✨ Features

- **Create Admin Users** - Instantly create new administrator accounts
- **Delete Admin Users** - Remove existing user accounts with confirmation
- **Glass-morphism UI** - Modern, responsive design with blur effects
- **Real-time Feedback** - Success/error messages with visual indicators
- **Secure** - Built-in validation and WordPress standards compliance

## 📋 Prerequisites

- WordPress 5.0 or higher
- PHP 7.4 or higher
- Admin access to WordPress installation

## 🚀 Installation

1. **Clone or download** the `wp-admin-manager.php` file
2. **Place the file** in your WordPress root directory (same folder as `wp-load.php`)
3. **Access** the tool via `https://your-domain.com/wp-admin-manager.php`
4. **Login** as an existing administrator to use the tool

```bash
# Example installation
cd /path/to/wordpress
wget https://your-domain.com/wp-admin-manager.php
